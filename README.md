- **Progressive Web App (PWA) & Service Worker**: `stale-while-revalidate` caching strategy providing offline persistence and instantaneous subsequent loads.

## Local Development & Testing

To inspect or serve the portfolio locally without external build steps:

```bash
# Clone repository
git clone https://github.com/goldengaco/goldengaco.github.io.git
cd goldengaco.github.io

# Serve with Python built-in HTTP server
python -m http.server 8080

# Or serve with Node.js
npx serve .
```

Navigate to `http://localhost:8080` in any modern web browser.
