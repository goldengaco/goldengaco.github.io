## 👨‍💻 Acerca del Portafolio

Portafolio web profesional de grado empresarial diseñado con un enfoque moderno, responsivo y de alto rendimiento visual (*Cyber-Slate & Tech Glass*). Desarrollado en Vanilla HTML5, CSS3 y JavaScript ES6+ sin sobrecarga de frameworks pesados, garantizando tiempos de carga ultrarrápidos (<50ms), accesibilidad WCAG AAA y compatibilidad total con GitHub Pages.

### ✨ Características Principales

- 💻 **Terminal CLI Interactivo**: Emulador de línea de comandos en tiempo real con comandos como `help`, `skills`, `projects`, `certs`, `whoami`, `uname -a`.
- ⚡ **Efecto de Escritura Dinámico**: Presentación interactiva de roles y especialidades en el Hero Header.
- 🎯 **Matriz de Habilidades por Competencias**: Stack técnico de 25+ tecnologías (PostgreSQL, Informix, Netezza, Yellowbrick, GCP, AWS, RHEL, Fedora, Zabbix, Python, Rust, Go).
- 🎓 **Sección de Certificaciones Verificables**: Acreditaciones con enlace directo a credenciales oficiales (GCP, AWS IAM, Linux SysAdmin, Git/GitHub, PostgreSQL DBA, MuleSoft).
- 📂 **Showcase de Proyectos y Herramientas**: Catálogo modular de herramientas empresariales y desarrollos personales (*MuleRadarVcore*, *GCP Hardening Suite*, *DBA Migration Framework*, *Rust Parallel Suite*).
- 🚀 **Progressive Web App (PWA) & Service Worker**: Soporte offline completo y caché inteligente *stale-while-revalidate*.
- 🌐 **SEO Rich Snippets & IA**: Marcado semántico JSON-LD (Schema.org), feed RSS (`feed.xml`) y especificación `llms.txt` para agentes de IA.
